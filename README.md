
🛒 NexaMart – E-Commerce Platform

NexaMart is a full-stack e-commerce web application developed using Django, providing a user-friendly platform for online shopping with a responsive interface and database integration.

🚀 Features

- Responsive and user-friendly design
- Product browsing and shopping
- Dynamic frontend interactions
- Django-powered backend
- MySQL database integration

🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django
- Database: MySQL
